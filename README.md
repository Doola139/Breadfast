Javascript extension shortcuts in Breadfast App
=======
# 🍞 Breadfast RMS Helper v2.0

## كلمة المرور: `asd123`

## الاختصارات:

| الاختصار | الوظيفة |
|---------|---------|
| `Alt + 1` | نسخ الهاشتاج برقم الأوردر (مثال: `#0306`) |
| `Alt + 2` | نسخ الرقم التسلسلي من الأوردر المفتوح |
| `Alt + 3` | نسخ "حضور عميل فرع..." حسب الفرع في الأوردر المفتوح |
| `Alt + 4` | نسخ الرقم التسلسلي + طريقة الدفع (كاش/فيزا) |

## ⚠️ مهم جداً:
- الاختصارات بتقرأ من **الأوردر المفتوح على الشمال** (الـ Detail Panel)
- لازم تكون فاتح أوردر عشان الاختصارات تشتغل صح
- لو مش فاتح أوردر هيقولك "افتح أوردر الأول"

## طريقة التثبيت:
1. افتح Chrome وادخل على `chrome://extensions/`
2. فعل "Developer mode" من فوق يمين
3. اضغط "Load unpacked" واختار مجلد الـ extension
4. افتح صفحة Breadfast RMS واستمتع!
